# 🛠️ VS Code: Essential Shortcuts
 
> Windows/Linux shortcuts. On macOS, most use `Cmd` instead of `Ctrl` and `Option` instead of `Alt`.
 
## 🔗 Chords: `Ctrl + K`, then...
 
Press `Ctrl + K`, release, then press the second combination.
 
| Shortcut | Action |
| :--- | :--- |
| `Ctrl + K`, `Ctrl + S` | Open keyboard shortcuts |
| `Ctrl + K`, `Ctrl + C` | Comment selected lines |
| `Ctrl + K`, `Ctrl + U` | Uncomment selected lines |
 
## ⚡ Single Shortcuts
 
| Shortcut | Action |
| :--- | :--- |
| `Ctrl + Shift + P` / `F1` | Open command palette |
| `Ctrl + P` | Quick open file |
| `Ctrl + Shift + F` | Search in all files |
| `Ctrl + ,` | Open settings |
| `` Ctrl + ` `` | Toggle terminal |
| `Ctrl + B` | Toggle sidebar |
| `Ctrl + D` | Select next occurrence |
| `Alt + ↑` / `Alt + ↓` | Move line up or down |
| `Ctrl + /` | Toggle line comment |
